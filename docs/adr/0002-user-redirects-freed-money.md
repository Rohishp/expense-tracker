# The Plan forecasts freed money, the user redirects it

When a Goal is funded, its Installment is freed for later periods. The Plan forecasts each Freed Installment, but it never moves that money by itself: the user chooses to give one or more Goals a Top-up, add to the Savings Pot, add a Goal, or leave it as Surplus. A Lump Sum is the one-off equivalent and lowers a Goal's Installment. We rejected having the algorithm re-spread freed money across Goals month by month, because the user wanted to decide where it goes, and an automatic re-spread would change Installments the user never chose. Installments therefore stay even; a Top-up is a separate amount on top. Each redirect is checked against the money still free from its start date onwards, so the same money cannot be redirected twice.
