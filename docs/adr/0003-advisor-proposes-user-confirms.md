# The Advisor proposes changes, the user confirms them

The Advisor answers what-if questions and may propose changes to Income, Obligations and Goals, which extends ADR 0001 (an LLM only suggests a Goal's Importance and Dependencies) for this one feature. It only proposes: every number comes from the Plan's deterministic algorithm, a proposal may only change an Income or Obligation amount the question gave and only remove a Goal or Obligation the question named, and nothing is saved until the user confirms, when the proposal is checked again against fresh data. We rejected letting the Advisor save changes itself, because there is no undo and a model can ignore a rule written in its prompt, and an Advisor that only answers, because the user would then re-enter every change by hand.
